# MVP-4X Research Screening Baseline

Scope: research_only, exploratory_only, weak_label_target, no_final_labels,
no_ground_truth_claim, no_production_claim.

The MVP-4X regime-policy consolidation track may package a research-only
screening baseline when repeated blocked validation, permutation controls,
ranking audit, and calibration/error analysis support bounded anomaly ranking
inside supported exploratory cohorts.

This document records the allowed interpretation:

- The baseline is for research-only screening and anomaly ranking.
- It is not an absolute channel-fraction predictor.
- It is not a production model.
- It does not produce final labels.
- It does not establish ground truth.
- It is not validated outside supported cohorts.
- It does not approve a formal production regime split.
- It does not approve a formal orientation filter.
- It does not approve STC, APES, or deep learning.

Human review is required before any formal regime-policy change, label semantic
change, advanced signal-processing route, final-label generation, or production
claim.
